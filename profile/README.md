<h2>一、数量由什么决定</h2>
<p>三件事决定你能用几个：运营商分配给你的地址段、专线的接入方式、以及服务器或路由器上的地址槽位。</p>
<p>家用宽带通常一个动态地址，企业专线可以买到四址、八址、十六址的小段，再往上要单独申请。</p>
<p>地址段大小直接影响价格，四址段和十六址段的月费差距明显，先算清实际需要几个再谈。</p>
<h3>先数设备再定档</h3>
<p>把所有需要独立出口的设备列一遍，含监控、打印机这类容易被忘掉的，数量出来档位自然就定了。</p>
<h2>二、常见档位</h2>
<p>四址段是最常见的入门配置，其中一个做网关，实际可用三个，够小型办公室或者几台服务器用。</p>
<p>八址段可用的更多，适合有多台设备、需要给每个业务固定出口的场景。</p>
<p>十六址及以上一般用于机房或规模较大的团队，采购周期更长，通常需要提供用途说明。</p>
<h3>四址段够不够用</h3>
<p>三台服务器加一台路由器刚好够，再多就要靠端口映射省地址，或者直接申请更大的段。</p>

<h2>三、专线怎么接进来</h2>
<p>常见三种：光纤直连给静态段、拨号方式给单址、以及多拨叠加，前两种最常用。</p>
<p>静态段方式把地址直接配在设备上，最稳定；拨号方式每次可能换地址，做固定出口不合适。</p>
<p>多拨能拿到多个地址，但要确认运营商允许，且每条会话独立计费或限速，实际带宽未必叠加。</p>
<p>接入前先问清光猫和路由器的接口类型和数量，接口不够就得加交换机，设备清单要提前拉。</p>
<h2>四、地址怎么落到服务器</h2>
<p>最简单是把地址配在服务器网卡上，一址一卡或者一卡多址都可以，配完确认路由表正确。</p>
<p>地址不够分的时候，用路由器做一对一映射，把公网地址映射到内网服务器，服务器侧不用改配置。</p>
<h3>映射与直绑的取舍</h3>
<p>直绑延迟低、排错简单；映射省地址、方便统一管理。业务对延迟敏感就直绑，设备多就映射。</p>
<p>做映射时注意端口冲突，同一个公网地址上两个服务抢同一个端口，只能改其中一个。</p>
<h2>五、带宽和数量是什么关系</h2>
<p>地址数量和带宽是两条独立的账，买八个地址不会自动多给你带宽，带宽要单独谈。</p>
<p>每个地址上的业务都有峰值，把各业务的峰值加起来，再留三成余量，才是应该买的带宽。</p>

<h2>六、以后怎么扩</h2>
<p>先扩带宽再扩地址，多数卡顿是带宽不够而不是地址不够，顺序搞反会白花钱。</p>
<p>地址段可以向上申请扩容，但同段内追加比新开一段更好管理，路由条目也少。</p>
<p>扩容前先做一次用量盘点，看清峰值出现在什么时段，再决定是加带宽还是加线路。</p>
<h2>常见问答</h2>
<h3>一个服务器能用几个公网IP？</h3>
<p>答：取决于运营商分配和网卡配置，常见是四到十六个。技术上可以更多，实际受带宽与管理成本限制。</p>
<h3>四个地址为什么只能用三个？</h3>
<p>答：网段里通常有一个地址被用作网关，有时还有一个广播地址，实际可分配给设备的会少一到两个。</p>
<h3>专线带的地址能分给其他地点的设备吗？</h3>
<p>答：可以，通过专线或隧道把地址延伸到分支，但延迟和故障点会增加，跨城使用要先测链路质量。</p>
<h3>地址越多越稳定吗？</h3>
<p>答：不是。稳定性来自线路质量和冗余设计，地址只是数量。单条线路给再多地址，断了还是一起断。</p>
